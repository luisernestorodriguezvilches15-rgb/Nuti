# Funciones Edge pendientes

Aquí se añadirán las funciones seguras del servidor para:
- `analyze-meal`: análisis de fotografías de comidas con un proveedor de IA.
- `coach-chat`: asistente nutricional.
- `delete-account`: eliminación de cuenta y datos.

No coloques claves privadas de IA o Supabase dentro de la aplicación Android. Configúralas como secretos del proyecto Supabase cuando se implemente el backend.
